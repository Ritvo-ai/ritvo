# Support

Ritvo is an early, pre-alpha project with a single maintainer.

Support is best effort, with no SLA. Questions go in GitHub Issues. There is no private or paid support.

## Where to ask what

| You want to | Go to |
| --- | --- |
| Ask a question | [Open a question](https://github.com/Ritvo-ai/ritvo/issues/new/choose) |
| Report a bug | [Open a bug report](https://github.com/Ritvo-ai/ritvo/issues/new/choose) |
| Propose a feature or a change to the spec | [Open a feature request](https://github.com/Ritvo-ai/ritvo/issues/new/choose) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |
| Raise a conduct concern | contact@ritvo.ai, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before opening an issue, please search existing issues and read [docs/SPEC.md](docs/SPEC.md). Do not paste real credentials, tokens, client configuration or client data into an issue; use fictional values.
