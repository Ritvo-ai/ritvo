# Trademark

"Ritvo" is the name of this project. The Apache-2.0 licence covers the code; it does not grant rights to use the project name or any logo (see section 6 of the [LICENSE](LICENSE)).

No trademark registration has been filed for the name. This page will be updated if one is filed. Until then, it states how the maintainer asks the name to be used.

## Use that is fine

- Referring to the project by name, for example "works with Ritvo", "an adapter for Ritvo" or "based on Ritvo".
- Saying that your adapter implements the Ritvo adapter contract, and that it passes the scenario suite if it does.
- Using the name in articles, talks, tutorials and books about the project.
- Distributing unmodified copies of Ritvo under its own name.

## Use to avoid

- Naming a product, service, company or domain "Ritvo", or something confusingly similar.
- Calling a modified version or a fork "Ritvo". Give it a different name and say it is based on Ritvo.
- Suggesting that the project or its maintainers endorse, certify or support your product, unless they have said so in writing.
- Calling an adapter "supported" or "certified" when it does not pass the scenario suite.
